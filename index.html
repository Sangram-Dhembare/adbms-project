TASK 1 · DATA SETUP

Collections & seed data

The sample project creates a campus_events database with clubs, events, and registrations. The complete seed and query script is included as mongosh.js.

use campus_events;
db.events.insertMany([ /* 3 event documents */ ]);
db.registrations.insertMany([ /* 4 ticket documents */ ]);
TASK 2 · EVENT DISCOVERY

Read & filter

Free events with over 50 seats, matching event tags, and Computer Science registrations.

db.events.find({ entryFee: 0, seatsAvailable: { $gt: 50 } });
db.events.find({ tags: { $in: ["coding", "hackathon"] } });
db.registrations.find({ department: "Computer Science" });
TASK 3 · REAL-TIME UPDATES

Atomic booking & check-in

Seat reservation guards against overselling. Sponsor insertion uses $addToSet to prevent duplicates.

db.events.updateOne(
  { _id: "EVT101", seatsAvailable: { $gt: 0 } },
  { $inc: { seatsAvailable: -1 } }
);
db.registrations.updateOne(
  { ticketId: "TICK-2026-001" },
  { $set: { checkInStatus: true } }
);
db.events.updateOne(
  { _id: "EVT101" },
  { $addToSet: { sponsors: "CloudInc" } }
);
